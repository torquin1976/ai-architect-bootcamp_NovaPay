# LocalStack Configuration Summary

## Current Setup

Both `docker-compose.yml` and `docker-compose.windows.yml` are configured to use **LocalStack Community Edition (Free)**.

## Key Configuration Settings

```yaml
environment:
  SERVICES: sqs                    # Only SQS (free service)
  LOCALSTACK_API_KEY: ""           # Empty string = Community Edition
  DISABLE_EVENTS: 1                # Disable Pro-only event features
  PERSISTENCE: 0                   # No persistence (Pro feature)
  SKIP_INFRA_DOWNLOADS: 1          # Skip Pro infrastructure downloads
  DEBUG: 0                         # Minimal logging
  AWS_DEFAULT_REGION: us-east-1    # Default AWS region
```

## What This Means

✅ **No License Required** - Empty API key means Community Edition
✅ **No Cost** - 100% free, no credit card needed
✅ **SQS Fully Supported** - SQS is a Community Edition service
✅ **No Pro Features** - Explicitly disabled to avoid warnings

## Services Used

| Service | Tier | Status |

## Verification

After starting LocalStack, verify it's using Community Edition:

```bash
# Check logs for Community Edition message
docker logs novapay-localstack 2>&1 | grep -i "community\|edition"

# Verify no API key is set
docker exec novapay-localstack env | grep LOCALSTACK_API_KEY
# Output should be: LOCALSTACK_API_KEY=

# Check SQS is available
curl http://localhost:4566/_localstack/health
# Should show: "sqs": "available"
```

## If You See Pro Warnings

Some informational messages about Pro features may appear - these are safe to ignore:

```
INFO: LocalStack Pro features are not available
INFO: To use Pro features, set LOCALSTACK_API_KEY
```

These are just informational. As long as SQS works, you're good to go.

## Upgrading to Pro (Optional)

If you ever want Pro features (not needed for this project):

1. Sign up at https://localstack.cloud/
2. Get your API key
3. Update docker-compose.yml:
   ```yaml
   environment:
     LOCALSTACK_API_KEY: "your-api-key-here"
   ```

**Cost:** Pro starts at $30/month (not needed for this project)

## Alternative: Real AWS SQS

Instead of LocalStack, you can use real AWS SQS:

**Pros:**
- Identical to production
- No LocalStack setup needed
- AWS Free Tier: 1M requests/month

**Cons:**
- Requires AWS account
- Requires AWS credentials
- Internet connection needed

**Setup:**
```yaml
# In docker-compose.yml
payment-service:
  environment:
    SQS_QUEUE_URL: https://sqs.us-east-1.amazonaws.com/YOUR_ACCOUNT/novapay-webhook-queue
    AWS_ACCESS_KEY_ID: your-key
    AWS_SECRET_ACCESS_KEY: your-secret
    # Remove: AWS_ENDPOINT_URL: http://localstack:4566
```

## Recommendation

✅ **Use LocalStack Community Edition** (current setup)
- Free
- No AWS account needed
- Perfect for local development
- Identical API to real SQS
